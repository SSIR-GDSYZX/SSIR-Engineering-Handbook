# 网站使用指南

SSIR Engineering Handbook 用于查找和维护可公开分享的机器人与工程技术知识。页面内容以 Markdown 编写；没有 Git 使用经验也可以先浏览、搜索或反馈错误。

## 网站板块

| 板块 | 适合查找的内容 |
| --- | --- |
| 学院 | 入门资料、开发环境和教程 |
| 项目 | 经批准公开的进行中或归档项目文档 |
| 工坊 | 3D 打印、激光切割及制造工艺资料 |
| 资产 | 经批准公开的设备说明、耗材资料和模板 |
| 技术 | 机器人、机械、电子、嵌入式、控制与人工智能主题 |
| 研究 | 研究资料和实验报告 |
| 安全 | 经审核并获准公开的安全文档 |
| 组织 | 网站使用、文档贡献及编写规范 |

具体内容会逐步补充；空白或占位页面不代表已有对应设备、项目或组织制度。

## 浏览和搜索

- 使用页面顶部的搜索框输入主题、关键词或文档标题；从结果打开相关页面。
- 使用桌面版左侧导航，或手机上的菜单按钮展开板块和子页面。
- 查找设备说明时先打开“资产 → 设备”；软件安装教程可从“学院 → 开发环境”查找；项目资料可从“项目”及其进行中、归档入口查找。
- 若暂时找不到内容，可尝试同义关键词，或通过文档反馈入口提出补充建议。

## 手机访问

使用手机浏览器打开 [SSIR Engineering Handbook](https://ssir-gdsyzx.github.io/SSIR-Engineering-Handbook/)。网站按移动屏幕布局；点击菜单浏览板块，点击搜索图标查找主题。无需安装专用应用。

## 反馈文档错误

在仓库提交[文档错误或改进反馈](https://github.com/SSIR-GDSYZX/SSIR-Engineering-Handbook/issues/new?template=documentation-error.yml)，提供页面链接、问题描述及建议。不要在反馈中粘贴个人信息、内部资产资料、采购记录、凭据或其他敏感内容。

## 参与贡献

可在文档页面点击“编辑此页”提出修改，也可通过 VS Code 编辑后提交 Pull Request。首次贡献请阅读[文档编辑与贡献指南](document-editing-guide.md)和[文档规范](document-standards.md)。内容经管理员或指定维护者审核、合并后，才会进入正式网站。
