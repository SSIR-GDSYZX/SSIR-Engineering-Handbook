# PETG（聚对苯二甲酸乙二醇酯）

## Material Overview（材料简介）

PETG（Polyethylene Terephthalate Glycol）是改性聚对苯二甲酸乙二醇酯，结合了 PLA 的打印易用性和 ABS 的一定机械性能。它韧性更好、耐温更高、耐化学性更强，适合功能原型和部分受力零件。

SSIR 活动室目前库存 Bambu Lab PETG HF White 一卷，以及透明/半透明 PETG 一卷（品牌及详细规格待确认）。

## Properties（材料性能）

| 属性 | 典型数值（通用 PETG，非特定品牌） |
|------|----------------------------------|
| 打印喷嘴温度 | 230–250 °C |
| 热床温度 | 70–90 °C |
| 玻璃化转变温度 | 约 75–85 °C |
| 密度 | 约 1.27 g/cm³ |
| 拉伸强度 | 约 50–60 MPa |
| 断裂伸长率 | 约 20–30 % |

> 上述数值为通用材料特性参考，非 SSIR 库存特定卷材的实测数据。具体品牌参数请以制造商官方说明为准。

## Applications（适用场景）

- 功能原型与测试零件
- 承受中等应力的结构件
- 耐化学品接触的零件
- 需要一定韧性的印花夹具

## Printing Considerations（打印注意事项）

- PETG 比 PLA 更容易拉丝（stringing），建议适当降低打印温度或增加回抽距离。
- 首层贴合力很强，建议在构板上使用分离剂（如胶棒），避免难以取下。
- 冷却风扇建议开启 30–50%，过高的冷却会导致层间粘合力下降。
- 打印速度不宜过快，以避免挤出不足。

## Moisture Sensitivity（吸湿敏感性）

PETG 对湿度敏感，吸湿后会出现：
- 挤出时发出“爆米花”声
- 表面出现气泡和银丝
- 机械性能下降

建议将 PETG 存放在密封容器中，附带干燥剂。

## Storage & Drying（储存与烘干）

- **密封防潮储存**：推荐用于长期储存，附带硅胶干燥剂。
- **普通货架储存**：适合短期使用，使用前检查丝材状态。
- **主动烘干**：如发现吸湿，可使用耗材烘干机在约 65–70 °C 下烘干 4–6 小时。具体温度和时间请以丝材制造商官方建议为准。
- **打印前检查**：观察丝材表面是否有气泡、变色或脆化迹象。

## Limitations（局限性）

- 易拉丝，需要调整回抽参数
- 耐磨性一般，不适合高摩擦零件
- 透明或半透明 PETG 打印后透明度会降低，呈现乳白色外观
- 对某些溶剂（如丙酮）不耐受
