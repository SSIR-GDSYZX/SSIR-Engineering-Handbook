# 3D 打印材料知识

本页汇总 SSIR 活动室常用 3D 打印耗材的工程知识，包括材料特性、打印注意事项、储存与烘干指南以及配置文件下载入口。

> **安全提示**：当活动室无人时，耗材烘干机必须关闭。不得因设备支持定时功能而默认允许无人运行。

## 支持材料

| 材料 | 说明 | 文档状态 |
|------|------|----------|
| [PLA](pla.md) | 普通聚乳酸，适合原型与教学用途 | draft |
| [PETG](petg.md) | 聚对苯二甲酸乙二醇酯，韧性更好、耐温更高 | draft |
