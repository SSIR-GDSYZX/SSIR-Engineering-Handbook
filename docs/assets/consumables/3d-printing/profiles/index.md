# 打印配置文件下载

本页提供经过验证的 3D 打印配置文件下载入口。

## 下载说明

每个配置文件至少说明以下信息：

- 打印机型号
- 材料类型
- 耗材品牌
- 切片软件及版本
- 喷嘴规格
- 配置文件版本
- 验证状态
