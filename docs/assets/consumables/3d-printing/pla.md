# PLA

聚乳酸

## Material Overview（材料简介）

PLA（Polylactic Acid，聚乳酸）是 3D 打印中最常用的热塑性材料之一，由可再生资源（如玉米淀粉、蔗糖）发酵制成。它打印难度低、翘曲小、无明显气味，适合原型制作、教学演示和非结构件制造。

SSIR 活动室目前库存 PLA 多种颜色（粉、黄、绿、蓝、橙），剩余量为近似描述，不作为实时盘点。

## Properties（材料性能）

| 属性 | 典型数值（通用 PLA，非特定品牌） |
|------|----------------------------------|
| 打印喷嘴温度 | 190–220 °C |
| 热床温度 | 50–60 °C（可选） |
| 玻璃化转变温度 | 约 55–60 °C |
| 密度 | 约 1.24 g/cm³ |
| 拉伸强度 | 约 50–70 MPa |
| 断裂伸长率 | 约 2–6 % |

> 上述数值为通用材料特性参考，非 SSIR 库存特定卷材的实测数据。具体品牌参数请以制造商官方说明为准。

## Applications（适用场景）

- 原型模型与外壳
- 教学模型与教具
- 非受力结构件
- 装饰品与模型

不适用于长期承受高温（>60 °C）或高应力的工程零件。

## Printing Considerations（打印注意事项）

- PLA 对打印环境温湿度不敏感，但长期暴露在高湿环境中会吸湿，导致打印时出现气泡、丝印或挤出不稳定。
- 首层贴合通常良好，建议使用普通构板或涂胶棒增强附着力。
- 冷却风扇建议开启 100%，有助于提升悬垂效果和表面质量。
- 退火处理可提升耐热性，但会导致尺寸变形，需谨慎使用。

## Moisture Sensitivity（吸湿敏感性）

PLA 对湿度敏感，长期暴露在环境湿度 >60% 时会逐渐吸湿。受潮的 PLA 打印时可能出现：
- 挤出口喷出气泡或微小水珠
- 表面出现丝印或粗糙纹理
- 层间粘合力下降

建议将 PLA 存放在密封容器中，并附带干燥剂。

## Storage & Drying（储存与烘干）

- **密封防潮储存**：将 PLA 放入密封容器，附带硅胶干燥剂，适合长期储存。
- **普通货架储存**：适合短期使用，使用前应检查丝材状态。
- **主动烘干**：如发现吸湿迹象，可使用耗材烘干机在约 45–55 °C 下烘干 4–6 小时。具体温度和时间请以丝材制造商官方建议为准。
- **打印前检查**：观察丝材表面是否有气泡、变色或脆化迹象。

## Limitations（局限性）

- 耐热性差，长期温度 >60 °C 会软化变形
- 脆性较大，抗冲击性差
- 不适合户外长期使用，紫外线照射会导致老化
- 不耐溶剂，接触某些化学品会溶解或变脆
