# 耗材储存与烘干指南

本页说明 SSIR 活动室耗材的储存方式与烘干要求，适用于 PLA、PETG、PETG HF 等常见 3D 打印耗材。

## 安全规则

**当活动室无人时，耗材烘干机必须关闭。**

不得因为设备支持定时功能而默认允许无人运行烘干机。

## 储存方式

### 密封防潮储存

- 使用密封容器（如储存盒、真空袋）存放耗材。
- 容器内附带硅胶干燥剂，定期更换或再生干燥剂。
- 适合长期储存（超过 1 周不使用的耗材）。
- 推荐用于对湿度敏感的材料（PLA、PETG、PETG HF 等）。

### 普通货架储存

- 适合短期使用（几天至一周内会消耗完的耗材）。
- 放置在远离阳光直射、热源和潮湿环境的位置。
- 使用前应检查丝材表面是否有吸湿迹象（气泡、变色、脆化）。

## 主动烘干

如发现耗材吸湿（打印时出现气泡、丝印、挤出不稳定等），可使用耗材烘干机进行烘干。

| 项目 | 说明 |
|------|------|
| 烘干设备 | 活动室耗材烘干机 |
| 适用材料 | PLA、PETG、PETG HF |
| 安全规则 | 活动室无人时必须关闭 |

### 烘干温度与时间

不编造统一适用于所有材料的烘干温度和时间。具体参数请以丝材制造商官方建议为准。常见参考范围：

- PLA：约 45–55 °C，4–6 小时
- PETG / PETG HF：约 65–70 °C，4–6 小时

> 上述温度和时间仅为通用参考，非 SSIR 验证数据。实际操作前请确认制造商官方说明。

## 打印前材料状态检查

在将耗材装入打印机前，应检查：

1. 丝材表面是否有气泡、水珠或变色
2. 丝材是否变脆，弯折时容易断裂
3. 丝材卷是否有受潮结块现象
4. 包装是否完好，干燥剂是否失效

如发现异常，应先进行烘干处理，或更换新的耗材卷。
