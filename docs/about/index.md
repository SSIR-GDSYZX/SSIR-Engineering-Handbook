# 关于本手册

本网站为 SSIR 工程技术文档平台的基础框架，目标是集中整理机器人与工程技术相关的可公开知识。当前结构用于后续协作，不代表任何具体项目、人员、设备或组织制度已经确认。

## 使用与维护

- 从[首页](../index.md)进入八大板块。
- 新增或修改内容前，参阅[贡献指南](../organization/contribution-guide.md)及[文档规范](../organization/document-standards.md)。
- 组织、设备、项目及安全信息应由授权人员核实后发布。
- 本仓库的许可证、公开范围、GitHub 组织和网站地址仍待管理人员确认。
