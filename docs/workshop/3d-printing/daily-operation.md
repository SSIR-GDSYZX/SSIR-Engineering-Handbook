# Bambu Lab A1 日常操作

本页说明 SSIR 活动室 Bambu Lab A1 打印机的日常操作流程。

## 打印前检查

1. 检查构板是否清洁，无油污和残留物
2. 检查丝材是否干燥，无吸湿迹象
3. 检查喷嘴是否有堵塞或残留
4. 确认切片文件已正确导出并传输到打印机
5. 确认活动室有人在场（无人时不得启动打印或烘干）

## 材料选择与装载

- 根据零件要求选择合适的材料（PLA、PETG、PETG HF 等）
- 确认丝材品牌与类型匹配所选打印配置
- 将丝材卷放入料架，穿过导料管进入挤出机
- 在打印机界面上进行丝材装载，确认丝材从喷嘴正常挤出

## 切片文件检查

- 确认切片软件版本与打印机固件兼容
- 确认材料设置与实际使用的丝材一致
- 确认喷嘴规格与打印机实际喷嘴一致（A1 标配 0.4 mm 喷嘴）
- 确认支撑结构、底层贴合和打印方向合理

## 打印过程观察

- 首层打印时观察贴合情况，如发现翘边或位移应立即暂停
- 观察挤出是否稳定，无漏料或堵塞迹象
- 观察打印头移动是否顺畅，无异常噪音
- 打印期间保持活动室通风

## 打印结束后的操作

1. 等待构板冷却到安全温度后再取下模型
2. 小心取下打印件，避免损坏构板表面
3. 清理构板表面残留物
4. 将多余丝材退料并妥善存放
5. 整理活动室工具和耗材，恢复整洁

## 活动室设备整理

- 打印结束后关闭打印机电源（如无其他用户正在使用）
- 耗材烘干机在活动室无人时必须关闭
- 工具放回指定位置
- 废料和支撑结构残余清入垃圾桶
